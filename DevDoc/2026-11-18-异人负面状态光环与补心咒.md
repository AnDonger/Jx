## 范围及用户确认

本轮依据正式服 `20261118_134208_94.log`、`20261118_134540_15.log` 完善异人攻击负面状态、光环及补心咒。日志目录为 `F:/mxd/VsFsbServer/tests/build/x64/Debug/DataLog`。

原项目友方关系没有队伍优先判断，同种光环也没有有效来源的最高等级保护。参考 `fsb2_Source_code/Client/Core/Src/KNpcSet.cpp` 和两个 Jx1 项目，可见队伍与 PK 关系处理，但未在有效 Resources/settings 中找到用户描述的完整优先规则。已向用户说明差异，用户明确回复“按此规则实现”：

1. 先判断受益资格：自身及自己的召唤物；其次同队角色及其召唤物；非同队则要求双方实际阵营相同，且双方均不是自由 PK。
2. 同队不受跨阵营或自由 PK 限制。未组队自由 PK 只影响自身及自己的召唤物。
3. 召唤物沿用主人关系，但按自己的位置单独检查技能距离、地图及存活状态。
4. 符合资格的同种光环取最高等级。自身低等级光环也允许被队友高等级光环覆盖；来源身份不优先于等级。
5. 高等级来源停用、死亡、换图、离开范围、失去资格或实体槽位复用后，允许低等级有效来源在后续刷新时接替。

受益关系单独实现，没有改变攻击技能的原敌我判断。技能数值、范围、消耗及持续时间继续读取原技能表和 Lua。本轮没有新增或修改 Resources，没有修改客户端，也没有新增 Lua 接口。

## 源码修改

本轮修改7个文件，均位于 `Sources/Core/Src`；开始前快照及独立差异位于 `Test/YirenEffects20261118/Before`、`source-changes.diff`，保留了前轮未提交修改。

| 文件 | 修改及作用 |
| --- | --- |
| KNpcSet.h、KNpcSet.cpp | 新增通用 GetSupportRelation，召唤物转换为主人关系；检查真实队伍成员身份及双方阵营，避免只凭过期队伍编号获得资格。 |
| KSkills.h、KSkills.cpp | 友方施法采用受益资格判断；识别非伤害友方范围技能，通过原区域索引枚举范围目标；新增有效光环来源检查。玩家范围治疗只影响玩家及有合法主人的召唤物。 |
| KNpc.h、KNpc.cpp | 状态记录来源槽位、实体ID及光环标记。在发送客户端同步前保护仍有效的高等级光环；失效后允许较低等级接替。补心咒恢复参数按线上同步，重复施法重新进入回血处理。 |
| KNpc.cpp | 友方治疗不触发召唤物报复；召唤物装备重算时，把状态链表中的撤销值还原为正向效果后重放，修复光环加成反向；跳过药品恢复状态，避免重算触发重复恢复。 |
| KMissle.cpp | 对普通怪物成功命中且携带负面状态时，即使没有直接伤害，也进入原命中熟练度流程，修复斩心咒、破甲咒不修炼的问题。 |

光环按原约10帧周期刷新，状态持续60帧。高等级来源失效后，有较低等级有效来源时由下次刷新接替；没有可接替来源时，旧状态按剩余时间自然到期，不在关系变化瞬间强制撤销。

本轮没有把治疗熟练度改为每次施法增长。光环原10秒修炼及修炼 BUFF 倍率继续使用已有逻辑。
