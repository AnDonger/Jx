# 移动回弹、闲置掉线与物品交互外观修复

本轮接续用户实测：头像、初始耐久和技能列表正常，但移动后返回初始位置，重登位置不变；拿起武器后变成靖人，出现国战死亡惩罚和顶部图标；闲置后断线重连。

## 原因与修改

所有运行逻辑均修改现有 C/C++ 模块。未创建资源或配置，未修改客户端。测试辅助脚本、抓包及工作产物均在 `Test/PlayerInteraction`。

1. **移动请求未接入。** 真实日志有 227 条 `0x50` 跑动和 22 条 `B8/1E` 停止请求。旧分发表将 `0x50` 作为未实现的旧受伤消息，服务端没有移动，周期 `4E` 位置同步将客户端拉回。`KProtocolProcess.cpp/.h` 接入当前格式，将目标交给现有指令队列、寻路、碰撞和逐帧步进。停止动作使用 `KNpc::StopMovement()`，不采用客户端上报坐标传送，也不覆盖其他排队动作。角色保存继续使用内核权威坐标。
2. **走跑广播仍为旧版。** 当前 GUI IDA 的 `7648E0/764790` 消费 20 字节走跑消息，旧代码发送 13 字节。`KNpc::DoRun/DoWalk` 改为当前布局，保留原区域广播流程。
3. **心跳回复长度与编号不匹配。** 当前客户端回复 `7A`，长度 13；旧代码按旧枚举和 9 字节结构检查，导致回复未被接受，最终超时。`KSOServer.cpp` 按当前挑战回复处理并核对原样回送的挑战值，记录运算结果和未知本地标识，不将它们误当客户端时钟，也不发送旧版时钟回包。挑战运算本身尚未实现为认证校验，本轮解决保活互通。
4. **周期外观零占位被解释成变身。** 当前 GUI IDA 分发表 `7623A0` 的 `4B` 处理器是 `7680D0`。消息 `+21` 低 15 位为形象值，`0x7FFF` 转换为 `-1`，恢复角色本体；零值会选择 NPC 第 0 类。原代码全零初始化后未赋值，拿起武器触发外观刷新时变成靖人。普通角色现在发送 `AppearanceType=0x7FFF`、`AppearanceFlags=0x08`。同时按当前处理器修正 `4A/4B` 的 PK、战斗、睡眠、帮会和骑乘状态位。
5. **国战死亡惩罚是误变形的副作用。** GUI 静态链条：`7680D0` → `73B1E0` → Core 事件 182，参数 0 → `4765E0` → `4B5FF0` 添加 EffectKind 0 图标。归档中已找到多份原始 `bufferconfig.ini` 内容，EffectKind 0 的标题确为“国战死亡惩罚”，例如 `Resources/资源归档/未确认原名/serverlist.pak/00933-451fb542.bin`、`02220-a5f6229d.bin`。本轮没有恢复或新增这份配置；修正错误变形字段即可阻止这条错误添加路径。顶部额外图标的独立来源尚未确认。

公共结构放在 `Headers/KProtocol.h`；`CoreServerShell::CheckProtocolSize` 对当前跑动、停止、心跳执行独立边界检查。未知扩展字段保留未知命名与固定值。

客户端基准 SHA-256：`7179134950a58df1271e36c3f1ddcd2f12c4e0c054032175166f59faf090e200`。分析使用现有后台 GUI IDA，没有更换客户端或关闭用户 IDA。
