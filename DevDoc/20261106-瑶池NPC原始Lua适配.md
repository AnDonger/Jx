# 瑶池 NPC 原始 Lua 适配（2026-11-06）

## 范围与资源依据

沿用地图 52（瑶池）实际加载的 28 处 NPC 和 `Resources/script/瑶池` 原始 Lua。未修改原 Lua、NPC 坐标或配方，未新增资源或配置。本轮是这一批原脚本接口的适配，尚未完成瑶池全部玩法。

对照 `Jx1-Thiendieuvs2022`、`jx1-vs2022` 和 `fsb2_Source_code` 的脚本结构。后者客户端中的若干服务端接口仅有空函数，不能作为完整实现。`PhongThan` 中同名接口仅作参数及已有行为对照，实际材料、费用、等级、任务进度和成功条件以本项目原始 Lua 与物品表为准。

## 源码修改

- `Sources/Core/Src/KSortScript.cpp`：区分 Lua 的 `..` 字符串连接与对象方法调用。原来的预检把 `..GetName()` 判成动态调用，错误阻断了正常的广播与奖励分支。保留未知接口及真正动态调用的检查。
- `Sources/Core/Src/ScriptFuns.cpp`：补充 `DelItem2`、`GetItemLevel2`、`IsExistItem`、`AddNormalItem2`、`AddNormalItemPile`、`GetCredit`、`DecCredit`、`WasteCopperCash` 等原脚本接口。物品生成和堆叠仍走现有模板、`ItemSet` 和 `KItemList`。
- `Sources/Core/Src/KPlayer.cpp`：初始角色同步读取持久声望；瑶池 NPC 的已验证回调进入物品交换保护。
- `Sources/Core/Src/KSortScript.h`：声明 NPC 回调交换保护类，实现在现有 `ScriptFuns.cpp`，未增加平行服务。

`GetItemLevel2` 返回普通背包中指定三元组物品的最高等级；交付时仍按完整四元组精确扣除。法宝配方的第四参数是资源等级，不能当作绑定标志。绑定与非绑定法宝引用各自原表条目。

`GetCredit` / `DecCredit` 使用现有 `TASKVALUE_REPUTE=100`，与本服 `AddRepute` / `GetRepute` 共用存档。未另建余额，也未在本轮增加自动声望增长规则。

旧 Lua 的材料奖励有等级 1 的引用，而当前新材料表没有等级列、以等级 0 保存：仅当原材料等级 1 无模板时，按同类别等级 0 查找；装备等级不作这种转换。六参数创建接口兼容原脚本第七参数为 0 的调用，其余未确认参数仍拒绝。

## 交换失败保护

仅当前交互 NPC 位于瑶池且脚本 ID 相符时启用。进入回调时保存随身物品的完整属性、GUID、数量和位置，以及金钱、任务进度与任务日志；经验奖励延后至回调成功才结算。物品创建、入包或扣材料失败时中止回调并恢复这些状态，显示明确失败提示。装备和仓库不参与原任务的背包交付。

原 `AddEventItem` 在这一范围内使用正常入包流程；满包时不再为了奖励把原鼠标物品扔到地面。若恢复出现异常，则禁止本次角色覆盖保存并输出日志。

## 本批已覆盖的主要原始分支

- 龙吉公主：注入人魂的原始材料和装备转换。
- 琼霄娘娘、碧霄娘娘：地魂、天魂的材料、现金、声望与幸运物条件；成功率与奖励仍由原 Lua 决定。
- 镇元大仙：绑定及非绑定法宝定做，按原表等级与原费用扣除、生成。
- 函芝仙子：装备收集、情报交付的进度、费用和经验；按最高持有等级交材料。
- 赤松子：10 点声望兑换他山之石，以及原介绍对白。
- 二郎神：3 颗原任务种子兑换 1 件任务奖励物品。
- 雷震子：玉石还原，优先使用原配方材料，否则扣对应铜钱；扣费通知携带实际数量。
- 原来可执行的医生、商店、仓库、教师及普通对白继续复用现有实现。
