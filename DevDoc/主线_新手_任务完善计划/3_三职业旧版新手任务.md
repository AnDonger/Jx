# 3. 三职业旧版新手任务

优先级：P1。前置：阶段1、2。状态：实现与部署完成；原生8198项、三职业TLS登录／重登通过；客户端任务流程待验收。

## 目标与范围

先完成已有脚本最充分、等级门槛最低的18个旧新手任务，验证对话、物品、击杀、奖励、日志和存档的通用链路。它们与扩展48任务独立记录。

| --- | --- |
| 甲士 | 7暴雨之后、8新式武器、9使用仓库、10兼爱非攻、11勇士之刃、12六道轮回 |
| 道士 | 1百里挑一、2五火七禽、3使用仓库、4灵力修行、5文武双全、6六道轮回 |
| 异人 | 13强者之路、14新式装备、15使用仓库、16营救族人、17蚩尤神器、18六道轮回 |

## 实施顺序

1. 先接通三城NPC交谈／送信任务，再完成收集材料任务；复用有效Lua中既有状态值，不重新编号覆盖老角色进度。
2. 核对并按原用途恢复环狗将军、叛军队长、雪原巨兽、草仙婆婆、毒苔妖、失踪的族人等脚本。精确归档对应见阶段1。
3. 核实这些任务怪是否原本动态生成。确需固定实体时写入对应region_s.dat原生NPC段；保留地图备注、普通刷怪点、固定NPC、其他数据段，不恢复MonsterSpawns.ini。
4. 为任务怪接通正确死亡入口，保留原掉落和击杀归属检查。模板非空DeathScript优先于ActionScript.OnDeath，不能只设置后者。
5. 完成7级任务的10声望、12级生活技能书和任务物品组合等分支。成功交付后再推进，未满足条件时显示原说明。
6. 最后处理仓库与六道轮回。当前背包／仓库购买功能已经存在，旧“解锁仓库”任务不能重置、回收或缩减玩家已有权限；循环任务奖励概率按原脚本查证，不能自行设置。

## 验收条件

- 三职业分别从未接取到完成跑通；等级／职业／前置不满足时不能越级领取。
- 多NPC访问顺序、材料数量、组合、击杀和交付条件逐项核对；重复击杀、重复对话不重复发奖。
- 检查跨地图和重登恢复，以及同名扩展任务不误推进。
- 新角色和已有仓库扩展角色都能完成，既有物品、金钱、权限不受影响。

本阶段通过后，阶段4继续主线；扩展48任务在阶段7独立实施。
