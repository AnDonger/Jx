## 验证矩阵

| 维度 | 必查项目 |
| --- | --- |
| 职业与等级 | 三职业；门槛前／达到门槛；错误职业、错误前置、正确前置 |
| 状态推进 | 未接、进行中、可交付、已完成；多NPC不同访问顺序；重复对话和点击 |
| 任务物品与奖励 | 材料不足、恰好足够、额外数量；背包满、叠加满、任务物品版本；只扣正确材料和只发一次奖励 |
| 击杀与采集 | 正确／错误怪物、接取前后、任务怪死亡入口、普通掉落保留、组队归属、刷新和采集交互 |
| 日志与显示 | 标题、介绍、步骤、颜色、换行、寻路链接、完成移除；新增48节客户端可读性 |
| 存档与地图 | 过图、死亡、取消、重登、断线；未来／过去地图进入及返回；任务值与日志一致 |
| 失败一致性 | 发奖失败、Lua错误等可控失败；材料、金钱、声望、经验、日志、任务标记完整回滚 |
| 已有角色 | 不重置任务、背包、仓库权限；不补领重复奖励；其他NPC和怪物掉落无回归 |

## 通信和客户端核对

1. 使用当前 `F:/mxd/Jx/Release/Client/Game.unpacked.exe`，记录实际文件哈希。
2. 按现有包加载优先级同步客户端真正读取的 `settings/taskinfo.tbl`，核对最终内容。服务端仍读项目Resources；不要默认客户端能看到服务器目录中的文件。
3. 服务端任务表首次加载后缓存，发布时需安排安全重启；先确认在线角色保存与连接释放。当前只编写计划和补表，没有重启或部署。
4. 结合真实请求日志核对任务对话、日志同步、奖励和重登结果；模拟通信或编译成功不等于客户端任务已正常。
